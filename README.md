## Overview

Functional Programming Lab is a playground for exploring functional programming concepts in JavaScript, with a focus on React. The project includes reusable utilities and interactive demos.

---

## Features

- Modular functional utilities
- React components demonstrating functional patterns
- Modern development setup with Vite
- ESLint integration for code quality
- Material UI for rapid prototyping

---


## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/kevindev/functional-programming-lab.git
cd functional-programming-lab/only-once
npm install
```

---

## Usage

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the app.

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
